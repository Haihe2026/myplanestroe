# 宠物主题照相馆

发一张自家猫咪或狗狗的照片，选一个主题，做成宠物写真、宠物头像或纪念主题照。10 个主题，按张计费。

## 适合

- 想给猫狗做一张有主题的写真：皇家油画、古风、绅士正装、圣诞节日
- 想要一张宠物头像：卡通动漫、水彩画
- 想要好玩的分享图：赛博朋克、宇航员、海边度假、小探险家

## 不做

- 真人照片、人像写真（人像婚纱和写真 → 婚纱写真照相馆）；证件照换底 → 证件照换底助手
- 一张照片里有多只宠物或有人（请换成只有一只猫或狗的照片）
- 未经主人同意的他人宠物照片；伤害动物的画面
- 普通修图美颜、视频、动图、宠物买卖、拍摄预约、冲印邮寄

## 示例效果（10 个）

皇家油画宠物肖像、卡通动漫宠物、赛博朋克宠物、古风宠物、宇航员宠物、水彩画宠物、绅士正装宠物、海边度假宠物、圣诞节日宠物、探险家宠物。示例里的猫狗均为 AI 虚构，只展示效果方向，不是你的真实结果。

## 收费

按张计费，档位和金额在充值页上；同一账户的通用次数在已接入的技能间共享。没有免费试用。可以随时查剩余次数和消费记录。

## 反馈

有问题或建议直接说，确认原话后提交反馈，会给你一个反馈编号；之后说「查工单」就能看到处理进度和回复。提交反馈不扣次数。

## 说明

- 结果由 AI 生成，会尽力保持毛色、花纹和五官特征，但可能与实际有差异；公开发布时请按平台要求标注 AI 生成。
- 原照片不改动，结果另存为新的 PNG 文件。
- 首次对话会上报一次匿名安装标识和技能版本，仅用于统计使用情况和安装绑定，不含聊天内容和照片；设置环境变量 `MPS_PET_STUDIO_JOURNEY=off` 可关闭。
