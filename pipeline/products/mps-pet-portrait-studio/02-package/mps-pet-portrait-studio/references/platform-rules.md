# 照片与使用须知（可向用户转述）

- 发一张清晰的 PNG 或 JPG 照片：不超过 5MB，最短边至少 128 像素，最长边不超过 8000 像素、总像素不超过 2000 万；不支持动图。
- 照片里只有一只猫或狗，脸、眼睛、鼻子和耳朵清楚，光线均匀，效果更稳定；有多只宠物或有人时，请换一张或先裁成只剩它一只。
- 只用你自己的宠物，或已经征得主人同意的宠物照片。
- 画面有竖版 2:3、横版 3:2、方图 1:1 三种；做头像推荐方图。
- 结果不带标题文字、水印和品牌标志；宠物的脸、耳朵和鼻子不会被裁掉。
- 结果由 AI 生成，风格、配饰、背景和光影会变化，毛色、花纹和五官会尽力保持，但可能与实际有差异；照片里看不到的部位无法保证一致。
- 结果为 PNG 文件，原照片不改动。
- 用于公开发布时，按所在平台的要求标注 AI 生成。
