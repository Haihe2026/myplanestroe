# 提示词结构（仅供执行，不对用户复述，不点名）

提示词由 `scripts/studio.py` 的 `build_prompt()` 拼装，宿主不得自行改写或追加参数。结构为「动作动词 + 具体视觉参照 + 锁定句」，四段固定顺序：

1. **真实性与宠物身份（永远第一段）**：照片里只有一只猫或狗，做成同一只：保留物种、可见的品种外观、毛色和花纹的位置、眼鼻耳形状和自然体型，不改变毛色、不重新设计；照片里看不到的部位不臆造身份特征，低清照片不猜品种。
2. **动作 + 视觉参照**：把照片做成指定主题——风格、配饰、背景和光线按下表；服饰贴合动物体型，主体突出并保留安全边距，脸、耳和鼻不被裁掉。
3. **文字基线**：图中不得出现任何文字、数字、水印、标志或边框。
4. **安全基线**：只有这一只，不添加其他动物或人物，不出现他人品牌和标志；四肢、爪子和尾巴形态自然，不出现多余肢体。

空泛形容词（「可爱一点」「高级一点」）不进提示词，换成下表里可核对的视觉描述；审美类细节（色调、光线、构图）自动用稳妥默认，不追问。

## 各场景要点

| key | 风格、配饰与背景 | 锁定要点 |
|---|---|---|
| royal-oil | 深色宫廷背景、深酒红丝绒小披肩、传统油画笔触 | 保留耳形与胸口花纹 |
| cartoon | 清晰线条、柔和色块、浅色纯净背景的头像 | 耳尖上方留空；毛斑按原位置保留，不概括到消失 |
| cyberpunk | 紫青霓虹轮廓光、虚化未来街景，无招牌文字 | 脸部中性色补光，面部无遮挡 |
| ancient-chinese | 中式庭院与梅花、锦缎小披肩 | 服装顺着体型，眼鼻无遮挡 |
| astronaut | 贴身宇航服、透亮面罩、远处蓝色星球 | 面罩反光避开双眼，口鼻结构清楚 |
| watercolor | 纸张纹理、淡彩晕染、留白背景 | 眼鼻和关键花纹边缘清楚 |
| formal | 小礼服和领结、柔和影棚灯、素色背景 | 领结不挡胸前辨识斑纹 |
| seaside | 海边步道、蓝色海浪、自然光，横版留景 | 毛发纹理与身体比例按原图 |
| christmas | 暖色灯串、松枝、圣诞树虚化、小围巾 | 不戴遮眼帽子，高光不漂白毛色 |
| explorer | 森林小径、清晨自然光、轻便探险小领巾，横版 | 脸部和两只耳朵完整，不增加其他动物 |

用户要修改时，每次只改一件事；一句话里提了多个修改，拆成多次生成依次完成。
预告用语：「会尽力保持它的毛色、花纹和五官特征，细节差异可能存在」，不承诺完全一致。
