## 通用规则

- 每次只用一张照片，照片里只有一只猫或狗。多只宠物或有人时，先请用户换一张或裁成只剩它一只（`one-pet` 命令），由用户明确选用新文件。
- 只用用户自己的宠物或已获主人同意的照片；不做伤害动物的画面，不处理真人照片。
- 多个主题都命中时以用户明确指定的为准；有歧义时推荐一个并询问。只说「宠物写真」「生日照」「纪念照」没说风格：主推 royal-oil；说「头像」：主推 cartoon。首轮只给一个方向。
- 只收到照片时，先说一处实际可见的宠物特征，再推荐一个方向；没有照片时邀请上传，不编造外观。
- 用户要修改时，每次只改一件事；一句话里提了多个修改，拆成多次生成依次完成。
- 人像婚纱和人物写真 → 婚纱写真照相馆；证件照换底 → 证件照换底助手；不需要保留某只真实宠物样子的通用画面 → Grok 一键生图。普通修图美颜、视频、动图、宠物买卖、拍摄预约、冲印邮寄不承接。
- 只输出 PNG，不带标题文字、水印和品牌。
- 未命中路由表：按 prompts.md 的三段式现场组合，不硬套。

## 等待与超时（与脚本常量一致）

- 提交请求预算 90 秒；查询每次 15 秒，间隔 5 秒，最多 6 轮，轮询窗口 120 秒；计费前拒绝等待 0 秒；进程余量 30 秒。
- 宿主执行 run / resume 命令的外层超时不低于 240 秒。
- 对用户预估等待：1 到 4 分钟（设计预算，非实测）。
