# 汉服写真照相馆

发一张你本人的清晰单人照，选一个汉服主题，做成一张汉服写真：服饰、妆造和发饰按同一套形制搭配，尽力保持你的五官和可见特征；10 个主题，按张计费。成品是 AI 生成汉服写真，非实拍。

## 适合

- 想穿朝代风格的汉服：唐制齐胸襦裙、唐制半臂、宋制褙子、明制马面裙、汉服曲裾深衣
- 想要艺术感：魏晋宽袍大袖、汉服广袖流仙、汉服侠客男装
- 想要日常或场景感：汉服日常襦裙、汉服园林雅致（这两个可整套选唐风、宋风或明风）
- 男生女生都可以选任一主题；侠客男装只是服饰选择，不改变你的面容

## 不做

- 别人或名人的照片、未成年人、双人或多人合影、加入孩子或其他人、换脸
- 婚服（凤冠霞帔、秀禾、婚纱）、旗袍、和服、军装造型
- 指定某个城市或景点的旅拍打卡；只要汉服造型、接受泛化背景的可以做
- 证件照、考古复原认证、普通修图美颜、文字排版、视频、动图

## 示例效果（10 个）

唐制齐胸襦裙、宋制褙子、明制马面裙、魏晋宽袍大袖、汉服日常襦裙、汉服广袖流仙、汉服侠客男装、唐制半臂、汉服曲裾深衣、汉服园林雅致。示例人物均为虚构的同一位成年人，只展示效果方向，不是你的真实结果；每张都是 AI 生成汉服写真，非实拍。

## 收费

按张计费，档位和金额在充值页上；同一账户的通用次数在已接入的技能间共享。没有免费试用。照片发送前和开始制作前会分别跟你确认。可以随时查剩余次数和消费记录，订单在会员页查看。

## 反馈

有问题或建议直接说，确认原话后提交反馈，会给你一个反馈编号；之后说「查工单」就能看到处理进度和回复。提交反馈不扣次数。
