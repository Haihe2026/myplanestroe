# 照片与使用须知（可向用户转述）

- 发一张清晰的 PNG 或 JPG 单人照：不超过 5MB，最短边至少 128 像素，最长边不超过 8000 像素、总像素不超过 2000 万；不支持动图。
- 照片须是你本人、成年人、单人；脸清楚、没有被遮挡，效果更稳定；脸看不清时请换一张更清楚的照片。
- 不做名人或别人的照片，不加入孩子或其他人，不把几张照片里的人拼到一起，不换脸。朋友也想拍，请各自用本人照片分别来做。
- 每张只用一套汉服形制，服饰、妆造和发饰配套，不混穿不同朝代；不做婚服、旗袍、和服或军装造型。
- 唐、宋、明等主题按朝代风格参考来做，魏晋风、广袖流仙、侠客等是艺术主题，都不代表考古精确复原。
- 画面默认竖版 2:3，也可以做方图 1:1 或横版 3:2。
- 结果是 AI 生成汉服写真，非实拍：服饰、妆造、背景和光影会变化，五官会尽力保持，但可能与本人有差异；不能当作证件或任何证明。
- 结果为 PNG 文件，原照片不改动。
- 用于公开发布时，按所在平台的要求标注 AI 生成。
