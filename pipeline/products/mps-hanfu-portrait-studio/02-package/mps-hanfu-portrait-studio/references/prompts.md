# 描述结构（仅供执行，不对用户复述，不点名）

描述由 `scripts/studio.py` 的 `build_prompt()` 拼装，宿主不得自行改写或追加参数。三段式「动作动词 + 具体视觉参照 + 锁定句」，四条基线全部带上，顺序固定：

1. **真实性基线（永远第一段）**：只用这一张经本人同意的单人原照作为唯一人物依据，画面里恰好 1 位成年人物；只按已确认的一套服饰形制、妆发和场景做明确改动，未经确认的身体、身份和事实不改、不凭空设计。
2. **人物身份基线**：尽力保留本人可见的脸部结构、五官比例、肤色、自然年龄外观、发际线和体态；髻式和妆造可按套系更换，但不改脸、不改变性别特征，不套用示例人物或文物陶俑的脸型、体型和肤色；附上用户确认过的可见特征。
3. **动作与视觉参照**：编辑本人原照，只改服装、妆造、背景与光影；按下表的视觉参照和妆发，整套同一形制，不混搭其他朝代或主题部件；艺术主题注明不按考古精确复原处理。
4. **构图**：单人得体写真，脸部完整可见，姿态自然。
5. **文字基线**：图中不得出现任何文字、字母、数字、标牌、品牌、商标或水印。「AI 生成汉服写真，非实拍」只写在交付文字和结果一览页里，不让画面里出现。
6. **安全基线**：只有本人一位成年人物，不出现儿童或其他人；端庄得体、不透体；不出现他人品牌，不伪造身份，不做婚服、和服、旗袍或军装。
7. **锁定句**：保持唯一本人五官、可见真实特征与体态；不混套系，不套示例人物样貌。

空泛形容词（「好看一点」「有古风感」）不进描述，换成下表里可核对的视觉描述；审美类细节（色调、背景、光线）自动用稳妥默认，不追问。
