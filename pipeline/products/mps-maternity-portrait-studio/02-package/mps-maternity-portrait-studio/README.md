# 孕妈写真照相馆

发一张你本人孕期的单人照，选一个主题和孕期视觉档，做成孕期纪念写真。尽量保留你的样子；10 个主题 × 早期、中期、晚期三档，按张计费。成品是 AI 生成孕期写真，非实拍。

## 适合

- 想要影棚感：白纱轻盈棚拍、旗袍雅致、韩式清新、复古油画
- 想要自然光：户外草坪阳光、花海仙气、森系清新、海边度假暖阳
- 想要居家或夜晚氛围：简约家居温馨、夜景灯火温馨
- 孕期视觉档按你自己说的阶段选：早期（1–3 个月）、中期（4–6 个月）、晚期（7–9 个月）

## 不做

- 不是本人的照片、名人或他人的照片、假装怀孕的效果
- 两人、夫妻或多人合影，加入孩子、婴儿或其他人，把几张照片里的人拼到一起，换脸
- 性感化或暴露的照片；证件照、医学证明、孕周判断或健康建议
- 三人及以上的家庭合影 → 全家福写真照相馆；婚礼仪式写真 → 婚纱写真照相馆；目的地旅行打卡 → 旅行打卡写真照相馆；证件照换底 → 证件照换底助手；宠物写真 → 宠物主题照相馆
- 普通修图美颜、文字排版、视频、动图、线下预约、冲印邮寄

## 示例效果（10 个）

白纱轻盈棚拍、户外草坪阳光、花海仙气、复古油画、简约家居温馨、海边度假暖阳、旗袍雅致、韩式清新、森系清新、夜景灯火温馨。示例人物均为虚构的成年人，只展示效果方向，不是你的真实结果；每张标注的视觉档只是那张示例的呈现，不是给你的默认选择；每张都是 AI 生成孕期写真，非实拍。

## 收费

按张计费，档位和金额在充值页上；同一账户的通用次数在已接入的技能间共享。没有免费试用。可以随时查剩余次数和消费记录。

## 反馈

有问题或建议直接说，确认原话后提交反馈，会给你一个反馈编号；之后说「查工单」就能看到处理进度和回复。提交反馈不扣次数。

## 说明

- 结果由 AI 生成，是孕期纪念写真，不是实拍；孕期轮廓只是按你自述阶段的艺术呈现，不代表医学孕周；会尽力保持你的五官与发型，但可能与本人有差异。
- 服装只是你选的风格，不代表民族、宗教或其他身份。
- 原照片不改动，结果另存为新的 PNG 文件。
- 首次对话会上报一次匿名安装标识和技能版本，仅用于统计使用情况和安装绑定，不含聊天内容、照片或孕期信息；设置环境变量 `MPS_MATERNITY_PORTRAIT_JOURNEY=off` 可关闭。
