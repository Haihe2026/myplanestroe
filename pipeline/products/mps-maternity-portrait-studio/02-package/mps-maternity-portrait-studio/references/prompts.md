# 描述结构（仅供执行，不对用户复述，不点名）

描述由 `scripts/studio.py` 的 `build_prompt()` 拼装，宿主不得自行改写或追加参数。结构为「本人单人身份锁定 + 孕期视觉档 + 动作与视觉参照 + 文字基线 + 安全基线」，固定顺序：

1. **真实性与人物身份（永远第一段）**：以用户本人确认的这张单人原图为唯一人物依据，画面里恰好 1 位成年人物；保留实际可见的脸部结构、五官比例、肤色、发型、年龄外观和体态，不设计新脸、不换脸、不增删人物；附上用户自己确认过的可见特征（如眼镜）。
2. **孕期视觉档**：只写用户确认的那一档（早期 / 中期 / 晚期）的艺术呈现要点，注明不是医学孕周或标准肚形；不推断真实孕周或健康。
3. **动作 + 视觉参照**：只按所选主题改变服装、背景和光影，见下表；服装用用户确认的选择，没说就用主题默认；脸部完整可见。
4. **文字基线**：图中不得出现任何文字、数字、可读招牌、标志、水印、边框或凭证；「AI 生成孕期写真，非实拍」只写在交付文字和结果一览页里，不让画面里出现。
5. **安全基线**：只有本人一位成年人物，不出现儿童、婴儿、伴侣或其他人；服装端庄、胸腹完整遮盖，不裸露腹部、不性感化、不夸张身体；不推断民族或宗教身份；不出现他人品牌和标志；手和手指形态自然。

人物特征只用用户自己说出的可见特征，不推断年龄、民族、宗教或性别；示例里的虚构人物特征（年龄、肤色、发型）不得用于真实用户。对用户不展示拼装方式。空泛形容词（「好看一点」「高级一点」）不进描述，换成下表里可核对的视觉描述；审美类细节自动用稳妥默认，不追问。

## 孕期视觉档要点

| 档位 | 呈现 |
|---|---|
| early 早期视觉档 | 衣物下腹部曲线轻微自然，不强行添加明显隆起，不指定肚围或医学标准 |
| middle 中期视觉档 | 衣物下适度圆润的孕期轮廓，比例自然，不套早期或晚期的轮廓 |
| late 晚期视觉档 | 衣物下较饱满但比例自然的孕期轮廓，不夸张放大，不对应某个精确月份 |
