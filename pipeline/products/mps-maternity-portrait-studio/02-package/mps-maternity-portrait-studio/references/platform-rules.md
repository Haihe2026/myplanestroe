# 照片与使用须知（可向用户转述）

- 发一张清晰的 PNG 或 JPG 单人照：不超过 5MB，最短边至少 128 像素，最长边不超过 8000 像素、总像素不超过 2000 万；不支持动图。
- 照片里只有你本人一个人，脸清楚、没有被遮挡，效果更稳定；脸看不清时请换一张更清楚的照片。
- 只用你本人孕期的照片。不做他人或名人的照片，不做假装怀孕的效果，不加入孩子、伴侣或其他人，不把几张照片里的人拼到一起，不换脸。
- 孕期视觉档按你自己说的阶段选择（早期、中期、晚期），只是艺术呈现，不代表医学孕周或标准肚形；不需要也不提供任何医学证明或健康判断。
- 画面默认竖版 2:3，也可以做方图 1:1 或横版 3:2。
- 结果是 AI 生成孕期写真，非实拍：服装、背景和光影会变化，五官会尽力保持，但可能与本人有差异；不能当作证件或医学证明。
- 服装只是你选的风格，不代表民族、宗教或其他身份。
- 结果为 PNG 文件，原照片不改动。
- 用于公开发布时，按所在平台的要求标注 AI 生成。
