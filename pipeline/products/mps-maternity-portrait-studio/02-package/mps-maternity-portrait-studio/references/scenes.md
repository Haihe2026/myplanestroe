## 孕期视觉档（与主题独立，每个主题都可配三档之一）

| 档位 key | 名称 | 只按本人自述 | 呈现 |
|---|---|---|---|
| early | 早期视觉档 | 1–3 个月或孕早期 | 衣物下腹部曲线轻微自然，不强行添加明显隆起 |
| middle | 中期视觉档 | 4–6 个月或孕中期 | 衣物下适度圆润、比例自然的孕期轮廓 |
| late | 晚期视觉档 | 7–9 个月或孕晚期 | 衣物下较饱满但比例自然的孕期轮廓，不夸张放大 |

- 没有默认档：用户没说阶段时，和缺失的其他事实一次合并询问，不默认中期，也不按示例图的档位替用户选。`first-turn` 返回的 `stated_stage` 只是原话里明确自述的线索，仍须用户确认。
- 只按用户自述映射；说周数时请用户按月份或早/中/晚期说，不自行换算；说法前后冲突先澄清。不看照片估计孕期，不索要医学证明，不提供孕周判断或健康建议。
- 视觉档是艺术呈现，不是医学分期或标准肚形；十个主题与三档都可以组合，但不承诺每种组合的效果都一样。
- 示例图各自标了一个视觉档（早 3、中 4、晚 3），只展示这一张的效果；用户想看的主题×档位没有示例时如实说明，不拿别的图冒充，也不付费补图。

## 消歧（特异主题/服饰 → 一般风格词 → 泛化氛围词）

- 先看特异主题或服饰：旗袍 → qipao、油画 → oil、韩式 → korean、森系/森林/树林 → forest、花海/花丛 → flowers、白纱/纱裙/棚拍/影棚 → studio、海边/海滩 → beach、草坪/草地 → lawn、夜景/灯火/夜色 → night、家居/居家/沙发 → home。
- 没有特异词时再看一般风格词（复古、古典、雅致、淡雅、花园、户外、暖阳、绿意、暖调等）；只有「清新」「温馨」这类泛化氛围词时，先推荐一个稳妥方向再确认。泛化词不压过特异词：「森系清新」→ forest，「韩式清新」→ korean，「夜景温馨」→ night。不同层之间不看词序，只有同一层里才取原话最先出现的。`first-turn` 返回的 `suggested_scene` 已按这个顺序给出。
- 「晚期」「孕晚」是视觉档，不是夜景主题。
- 孕期海边纪念属于本技能，不当作旅行打卡；只要目的地打卡写真才转旅行打卡写真照相馆。孕期白纱、旗袍属于本技能，不做婚礼造型；明确要婚礼仪式写真才转婚纱写真照相馆。
- 多个都像时先推荐一个再问，首轮只给一个方向。

## 通用规则

- 只接用户本人、成年、本人自述确实在孕期的单人照（`--subject self --adult yes --pregnant yes --single yes`）。不是本人、不在孕期、假装怀孕、名人或他人照片、儿童或婴儿入镜、两人或夫妻合影、多人合成、换脸、性感化、证件或医学用途一律不承接；三人及以上家庭合影转全家福写真照相馆，两人或夫妻合影如实说本技能暂不支持。
- 脸部看不清或看不到图时，先请用户换一张更清楚的单人照（`--face-clear no`），不猜缺失的五官、年龄或民族。
- 三项同意缺一不提交：本人对这张照片的许可、同意把这张照片发送给图片服务及算力供应商处理、同意按张计费执行。本人确实在孕期的自述不能替代任何一项同意。
- 人物特征只用用户说出的可见特征；服装是用户选的风格，不推断身份。示例人物的年龄、肤色、发型不得套用到用户身上。
- 成品、示例和结果一览页都写明「AI 生成孕期写真，非实拍」；不承诺与本人完全一致，不承诺标准肚形或与某个月份严格对应。
- 用户要修改时，每次只改一件事；一句话里提了多个修改，拆成多次生成依次完成。换照片、主题、视觉档、服装或画幅都要重新 `plan` 并重新确认。
- 证件照换底 → 证件照换底助手；纯宠物写真 → 宠物主题照相馆。修图美颜、文字排版、视频、动图、线下预约、冲印邮寄、孕周或健康判断不承接。
- 只输出 PNG，每次 1 张；多张按单独任务逐张确认。
- 未命中路由表：按 prompts.md 的结构现场组合，不硬套，不扩大人数或画幅。

## 等待与超时（与脚本常量一致）

- 提交请求预算 90 秒；查询每次 15 秒，间隔 5 秒，最多 6 轮，轮询窗口 120 秒；计费前拒绝等待 0 秒；进程余量 30 秒。
- 宿主执行 run / resume 命令的外层超时不低于 240 秒。
- 对用户预估等待：1 到 4 分钟（设计预算，非实测）。
