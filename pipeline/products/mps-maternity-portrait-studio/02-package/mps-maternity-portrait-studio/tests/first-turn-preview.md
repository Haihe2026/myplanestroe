# 真机行为验收单（WorkBuddy 团队版技能）

由测试方在真实宿主中逐条验收，每条截图存证（截图不含账户信息）。真机没跑完的条目标「待验收」，不得写成已通过。

## 验收前

- 核对宿主实际加载的是本版 SKILL.md（version 1.0.1；市场安装副本路径可能带 `__skillhub` 后缀）。
- 每次改完都开新对话测，不用已加载旧版的对话。
- 全程只用包内离线示例和测试账号（测试时设置 `MPS_MATERNITY_PORTRAIT_TEST=1`），不做真实付费出图。
- 按可见的工具调用和最终回复判定。

## 场景（输入 → 通过标准）

| # | 输入 | 通过标准 |
|---|---|---|
| 1 | 只发一张本人孕期单人照 | 欢迎句一次；1–2 句真实可见的画面优点（不评价外貌或身材）；一个主推方向；两列示例链接表（每项含该图视觉档和「AI 生成孕期写真，非实拍」）；「这个方向可以吗？」；无链接/价格/账户 |

| 3 | 「你能做什么」 | 同首轮结构，不列长清单 |
| 4 | 带图「怀孕五个月了，想拍张孕期写真留念」 | 首轮结构，只给一个主推方向；不直接出图、不谈钱；中期只作线索，确认时仍要用户确认 |

## 判失败

没有真实积极反馈或编造细节；首轮堆多个方案或参数；示例不是两列链接表或用了内嵌图片；把占位符原样发出；把认可或沉默当成付费同意；未经同意打开充值页；暗示后续调整免费；失败时猜测费用；对用户说出内部术语；未经复述确认就提交反馈。
