# 旅行打卡写真照相馆

发一张你本人的单人照，选一个旅行目的地主题，做成旅行打卡写真。尽量保留你的样子；10 个主题，按张计费。成品是 AI 生成旅行主题写真，非实地拍摄。

## 适合

- 冬天想要冰雪或海岛氛围：哈尔滨冰雪主题、亚布力滑雪主题、三亚海岛暖冬
- 想要异域或古风感：圣托里尼蓝白、京都古风樱花、西安汉服古城
- 想要自然风光：沙漠星空、樱花季写真、草原蒙古包、古城灯火夜景

## 不做

- 两人、情侣或多人合影，把几张照片里的人拼到一起，换脸，名人或他人的打卡照
- 不是本人的照片，或孩子的照片不是由监护人提供
- 证件照、需要证明真实到访的图片、精确还原某个真实地标
- 三人及以上的家庭合影 → 全家福写真照相馆；婚纱照 → 婚纱写真照相馆；证件照换底 → 证件照换底助手；宠物写真 → 宠物主题照相馆
- 普通修图美颜、文字排版、视频、动图、旅行预订、线下旅拍预约、冲印邮寄

## 示例效果（10 个）

哈尔滨冰雪主题、亚布力滑雪主题、三亚海岛暖冬、圣托里尼蓝白、京都古风樱花、西安汉服古城、沙漠星空、樱花季写真、草原蒙古包、古城灯火夜景。示例人物均为虚构的成年人，只展示效果方向，不是你的真实结果；每张都是 AI 生成旅行主题写真，非实地拍摄。

## 收费

按张计费，档位和金额在充值页上；同一账户的通用次数在已接入的技能间共享。没有免费试用。可以随时查剩余次数和消费记录。

## 反馈

有问题或建议直接说，确认原话后提交反馈，会给你一个反馈编号；之后说「查工单」就能看到处理进度和回复。提交反馈不扣次数。

## 说明

- 结果由 AI 生成，是旅行主题写真，不是实地拍摄，不能当作去过当地的凭证；会尽力保持你的五官与发型，但可能与本人有差异。
- 服装只是你选的风格，不代表民族、宗教或其他身份。
- 原照片不改动，结果另存为新的 PNG 文件。
- 首次对话会上报一次匿名安装标识和技能版本，仅用于统计使用情况和安装绑定，不含聊天内容和照片；设置环境变量 `MPS_TRAVEL_PORTRAIT_JOURNEY=off` 可关闭。
