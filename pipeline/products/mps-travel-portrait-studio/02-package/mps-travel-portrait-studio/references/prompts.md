# 描述结构（仅供执行，不对用户复述，不点名）

描述由 `scripts/studio.py` 的 `build_prompt()` 拼装，宿主不得自行改写或追加参数。结构为「单人身份锁定 + 动作与视觉参照 + 文字基线 + 安全基线」，固定顺序：

1. **真实性与人物身份（永远第一段）**：以用户确认的这张单人原图为唯一人物依据，画面里恰好 1 位人物；保留实际可见的脸部结构、五官比例、肤色、发型、年龄外观和体态，不设计新脸、不换脸、不增删人物；附上用户自己确认过的可见特征（如眼镜）。
2. **动作 + 视觉参照**：只按所选主题改变服装、背景和光影，见下表；服装用用户确认的选择，没说就用主题默认；脸部完整可见。
3. **文字基线**：图中不得出现任何文字、数字、可读招牌、标志、水印、边框或旅行凭证；「AI 生成旅行主题写真，非实地拍摄」只写在交付文字和结果一览页里，不让画面里出现。
4. **安全基线**：人物服饰与姿态合宜；不推断民族或宗教身份；不出现他人品牌和标志；手和手指形态自然。

人物特征只用用户自己说出的可见特征，不推断年龄、民族、宗教或性别；示例里的虚构人物特征（年龄、性别、外貌）不得用于真实用户。对用户不展示拼装方式。空泛形容词（「好看一点」「高级一点」）不进描述，换成下表里可核对的视觉描述；审美类细节自动用稳妥默认，不追问。
