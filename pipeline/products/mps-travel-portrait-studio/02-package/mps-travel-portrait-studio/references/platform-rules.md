# 照片与使用须知（可向用户转述）

- 发一张清晰的 PNG 或 JPG 单人照：不超过 5MB，最短边至少 128 像素，最长边不超过 8000 像素、总像素不超过 2000 万；不支持动图。
- 照片里只有你一个人，脸清楚、没有被遮挡，效果更稳定；脸看不清时请换一张更清楚的照片。
- 只用你本人的照片；孩子的照片须由监护人提供并同意。不做名人或他人的打卡照，不把几张照片里的人拼到一起，不换脸。
- 画面默认竖版 2:3，也可以做方图 1:1 或横版 3:2。
- 结果是 AI 生成旅行主题写真，非实地拍摄：服装、背景和光影会变化，五官会尽力保持，但可能与本人有差异；画面里的地标只是主题意象，不能当作去过当地的凭证。
- 服装只是你选的风格，不代表民族、宗教或其他身份。
- 结果为 PNG 文件，原照片不改动。
- 用于公开发布时，按所在平台的要求标注 AI 生成。
