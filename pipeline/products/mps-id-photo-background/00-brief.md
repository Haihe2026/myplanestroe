# 选品单：证件照换底助手

- 建议 skill-id：mps-id-photo-background
- 品类：生图类（不是生图类的不要放进本流水线）
- 优先级：P1
- 状态：全新选品，未开发过。本单为流水线首单测试，用于验证 Muse → Codex → Claude → Codex 闭环链路。
- 目标用户：求职者、学生、考证与签证申请人；在报名、考试、求职、签证等场景下，需要一张符合规格的证件照，但手头只有普通照片或底色不对的旧证件照。
- 核心需求一句话：上传一张正面照片 → 得到符合规格的证件照（换底色 + 裁切到标准尺寸 + 像素对齐）。
- 主要场景（按需求量排序）：
  1. 白底一寸：求职简历、各类报名最常用
  2. 蓝底一寸：考试、证件办理
  3. 红底一寸：毕业证、学位证登记
  4. 白底二寸：报名表、登记表
  5. 蓝底二寸：考试报名
  6. 签证照：白底 35×45、美签 51×51
  7. 考试报名照：国考、教资、计算机等级考试
  8. 简历照：底色杂乱换成干净白底
  9. 社保、医保卡登记照
  10. 入学登记照
- 用户原话（真实说法，不是关键词）：
  1. “帮我把这张照片换成白底一寸的，明天报名要用。”
  2. “蓝底的能不能改成白底？单位只要白底。”
  3. “这张是一寸吗？帮我裁一下，底色换成红色。”
  4. “考试报名要蓝底二寸，照片我发你。”
  5. “简历上的照片底色太花了，换成白的干净点。”
  6. “签证要白底 51×51 的，能帮我做一张吗？”
  7. “毕业证登记要红底，帮我换一下。”
  8. “这张照片能换成白底吗？边缘别留蓝边。”
  9. “一寸蓝底，像素要 295×413，报名系统卡这个。”
  10. “帮我把背景换成白色，头发边缘别抠坏了。”
  11. “教师资格证报名要白底，尺寸别搞错。”
  12. “这张自拍能做成证件照吗？底换成蓝的。”
  13. “国考报名照片要蓝底，帮我处理一下。”
  14. “医保卡照片要白底一寸，明天交表。”
  15. “底色换成红的，顺便裁成二寸。”
  16. “照片底色不对被打回来了，帮我改成白底重交。”

- 主要竞品与差异点：
  - 微信小程序（拍点点、多多职业照、立得一寸照、证件照生成喵）：手机端轻便、免费或低价。差异：WorkBuddy 内对话式一次出图，不用跳小程序、不下 App；尺寸 + 底色 + 像素一次对齐，面向报名、简历、签证一次搞定的办公人群。
  - 美图秀秀、WPS、手机相册自带抠图：通用工具，部分高级功能要会员。差异：专做证件照规格，不做泛修图。
  - PS、专业照相馆：效果好但贵、慢、要出门。差异：几十秒出图、随用随付。
- 相邻自家技能（避免互相抢触发）：
  - 老照片修复大师：修老照片画质，不碰底色与尺寸，触发词不同。
  - 头像定制大师：头像风格化，不做证件照规格。
  - Grok一键生图：通用文生图，不接真实照片改底。
  - Listing优化大师：文字类，无冲突。
  - 边界：只做“真实照片 → 标准证件照”（换底 + 裁切 + 像素对齐），不做风格化，不做换装换发型，不修五官。
- 合规风险：（版权、肖像、平台规则、AI 标识）
  - 肖像：只处理用户本人或经授权的照片，不得用于伪造他人证件照。
  - 不改面部特征、不换服装发型，避免证件照失真导致审核不通过。
  - 明确告知用户：最终是否通过以发证、报名机关要求为准，不承诺包过。
  - AI 处理标识按平台规则标注；照片不做留存（首次对话匿名上报按 SOP）。
- 不做什么：
  - 不改五官、不磨皮美颜、不换装、不换发型。
  - 不做艺术风格、卡通、动漫证件照。
  - 不承诺官方审核通过。
  - 首版只做单张，不做批量多人证件照。
