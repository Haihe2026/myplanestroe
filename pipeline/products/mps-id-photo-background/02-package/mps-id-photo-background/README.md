# 证件照换底助手

发一张正面照片，把背景换成白底、蓝底或红底；报名系统要求具体像素（例如 295×413）时，再另存一份这个像素的图片。

## 适合

- 求职简历、考试报名、入学登记、证件办理需要的白底、蓝底、红底照片
- 照片底色不对被退回，需要换底重交
- 报名系统卡像素，需要按指定像素另存

## 不做

- 改五官、美颜、换衣服、换发型
- 多人合照、卡通或艺术风格头像
- 伪造证件或处理未经授权的他人照片

## 示例效果（10 个）

白底一寸、蓝底一寸、红底登记照、白底二寸、蓝底二寸、简历白底、295×413 像素、发丝边缘清理、入学登记照、机构指定尺寸。示例人物均为虚构，只展示效果方向，不是你的真实结果。

## 收费

按张计费，档位和金额在充值页上；同一账户的通用次数在已接入的技能间共享。没有免费试用。可以随时查剩余次数和消费记录。

## 反馈

有问题或建议直接说，确认原话后提交反馈，会给你一个反馈编号；之后说「查工单」就能看到处理进度和回复。提交反馈不扣次数。

## 说明

- 结果由 AI 处理，可能与原照片有细微差异；能否通过审核以报名或发证机构为准。
- 原照片不改动，结果另存为新的 PNG 文件。
- 首次对话会上报一次匿名安装标识和技能版本，仅用于统计使用情况和安装绑定，不含聊天内容和照片；设置环境变量 `MPS_ID_PHOTO_JOURNEY=off` 可关闭。
