## 通用规则

- 「一寸」「二寸」不自动等于某个像素、DPI 或文件大小；用户没给机构规格时，只换底色，提醒用户按报名系统写的像素告诉我再另存一份。
- 目标像素由脚本在本地居中裁切另存，并重新打开核对尺寸；目标像素宽不超过 1024、高不超过 1536，超出时如实说明做不到。
- 只输出 PNG。机构要求 JPG 或限制文件大小时，如实说明本技能目前只另存 PNG。
- 用户要修改时，每次只改一件事；一句话里提了多个修改，拆成多次生成依次完成。
- 签证照（例如美国签证）规定不得对照片做数字修改时，不承接，如实告知。
- 未命中路由表：按 prompts.md 的三段式现场组合，不硬套。

## 等待与超时（与脚本常量一致）

- 提交请求预算 90 秒；查询每次 15 秒，间隔 5 秒，最多 6 轮，轮询窗口 120 秒；计费前拒绝等待 0 秒；进程余量 30 秒。
- 宿主执行 run / resume 命令的外层超时不低于 240 秒。
- 对用户预估等待：1 到 4 分钟（设计预算，非实测）。
