# 证件照常见规范（可向用户转述）

- 不同报名系统、发证机构的像素、尺寸、文件大小要求各不相同，以对方页面写明的要求为准。「一寸」「二寸」只是常见叫法，不代表统一像素。
- 报名系统常写明像素（例如 295×413）。告诉我这个数字，我会在换好底色后另存一份这个像素的图片，并核对尺寸。
- 常见底色：白色、蓝色、红色。具体用哪种，以机构要求为准。
- 照片应为本人近期正面免冠照片，五官清晰，不戴有色眼镜。本技能只换背景，不改五官、不美颜、不换装、不改发型。
- 部分正式用途（例如一些国家的签证照片）规定不得对照片做数字修改，这类用途请按官方要求重新拍摄。
- 结果由 AI 处理，可能与原照片有细微差异；最终能否通过，以报名或发证机构的审核为准。
- 结果为 PNG 文件。对方只收 JPG 或限制文件大小时，需要另行转换。
