# 提示词结构（仅供执行，不对用户复述，不点名）

提示词由 `scripts/idphoto.py` 的 `build_prompt()` 拼装，宿主不得自行改写或追加参数。结构为「动作动词 + 具体视觉参照 + 锁定句」，四段固定顺序：

1. **真实性与人物身份（永远第一段）**：严格保留参考照片中这位人物的脸部身份、五官比例、表情、肤色、发型、衣着和姿态；不重画面部、不美颜、不换装、不改发型；构图和人物位置保持原样。照片里有多个人物时不承接（首版只做单人）。
2. **动作 + 视觉参照**：只把背景替换为均匀纯色（白 #FFFFFF / 蓝 #438EDB / 红 #D9001B / 用户指定色号），无渐变、无阴影、无纹理；清理头发丝和肩部边缘残留的原底色，不留色边。
3. **文字基线**：图中不得出现任何文字、水印、标志或边框。需要的文字一律不做。
4. **安全基线**：不添加其他人物，不添加任何品牌标志，不改变证件照的真实外观。

空泛形容词（「好看一点」「精神一点」）不进提示词；这类要求属于美颜，本技能不承接。

## 各场景要点

| key | 动作 | 锁定 |
|---|---|---|
| white-one / white-two / resume-white | 背景换白色 | 身份、五官、发型、衣着、姿态 |
| blue-one / blue-two | 背景换蓝色 | 同上 |
| red-one | 背景换红色 | 同上 |
| custom-pixels / custom-size / school | 背景换用户选的颜色，出图后本地裁切 | 同上 |
| edge-clean | 背景换用户选的颜色，重点清理发丝边缘原底色 | 同上 |

用户要修改时，每次只改一件事；一句话里提了多个修改，拆成多次生成依次完成。
预告用语：「会尽力保持五官与身份特征，细节差异可能存在」，不承诺完全一致。
