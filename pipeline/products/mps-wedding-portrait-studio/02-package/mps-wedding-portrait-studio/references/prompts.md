# 提示词结构（仅供执行，不对用户复述，不点名）

提示词由 `scripts/studio.py` 的 `build_prompt()` 拼装，宿主不得自行改写或追加参数。结构为「动作动词 + 具体视觉参照 + 锁定句」，四段固定顺序：

1. **真实性与人物身份（永远第一段）**：单人时保留这位人物的脸部身份、五官比例、发际线、肤色和年龄感，不美颜变脸；两人时逐人指代（左侧的人、右侧的人）、逐人锁定，两人不混脸、不互换特征，人数和左右相对位置不变。
2. **动作 + 视觉参照**：把照片做成指定主题——服装、背景、光线和构图按下表；光影和构图自然统一。
3. **文字基线**：图中不得出现任何文字、数字、水印、标志或边框。
4. **安全基线**：不添加额外人物，不出现他人品牌和标志；手和手指形态自然，不出现多余肢体。

空泛形容词（「好看一点」「高级一点」）不进提示词，换成下表里可核对的视觉描述；审美类细节（色调、光线、构图）自动用稳妥默认，不追问。

用户要修改时，每次只改一件事；一句话里提了多个修改，拆成多次生成依次完成。
预告用语：「会尽力保持五官与身份特征，细节差异可能存在」，不承诺完全一致。
