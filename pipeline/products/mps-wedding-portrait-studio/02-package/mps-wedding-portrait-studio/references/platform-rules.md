# 照片与使用须知（可向用户转述）

- 发一张清晰的 PNG 或 JPG 照片：不超过 5MB，最短边至少 128 像素，最长边不超过 8000 像素；不支持动图。
- 脸部清晰、正面或微侧、光线均匀的照片，效果更稳定。
- 写真只做单人。婚纱照可以是单人，也可以是照片里本来就同框的两个人；不会把照片里没有的人合成进来。
- 只用你本人或已经征得本人同意的成年人照片，不处理未成年人的照片，不换脸。
- 画面有竖版 2:3、横版 3:2、方图 1:1 三种。
- 结果由 AI 生成，服装、背景和光影会变化，五官会尽力保持，但可能与本人有差异。
- 结果为 PNG 文件，原照片不改动。
- 用于公开发布时，按所在平台的要求标注 AI 生成。
