# 婚纱写真照相馆

发一张照片，选一个主题，做成 AI 婚纱照或 AI 写真。婚纱 6 个主题、写真 4 个主题，按张计费。

## 适合

- 想试试婚纱照效果：白纱影棚、中式秀禾、草坪婚礼、海边婚纱、复古油画、韩式清新
- 想要一张主题写真或头像：汉服古风、油画艺术、赛博朋克、日系清新
- 有一张两人同框的合照，想做成情侣婚纱照

## 不做

- 未成年人的照片，或未经本人同意的他人照片
- 换脸，或把照片里没有的人合成进来
- 写真里的多人合照（写真只做单人）
- 证件照换底 → 证件照换底助手；不含人物的通用画面 → Grok 一键生图
- 视频、动图、线下拍摄预约、冲印邮寄

## 示例效果（10 个）

经典白纱影棚、中式秀禾服、户外草坪婚礼、海边度假婚纱、复古油画婚纱、韩式清新婚纱、汉服古风写真、油画艺术写真、赛博朋克写真、日系清新写真。示例人物均为虚构，只展示效果方向，不是你的真实结果。

## 收费

按张计费，档位和金额在充值页上；同一账户的通用次数在已接入的技能间共享。没有免费试用。可以随时查剩余次数和消费记录。

## 反馈

有问题或建议直接说，确认原话后提交反馈，会给你一个反馈编号；之后说「查工单」就能看到处理进度和回复。提交反馈不扣次数。

## 说明

- 结果由 AI 生成，会尽力保持五官与身份特征，但可能与本人有差异。
- 原照片不改动，结果另存为新的 PNG 文件。
- 首次对话会上报一次匿名安装标识和技能版本，仅用于统计使用情况和安装绑定，不含聊天内容和照片；设置环境变量 `MPS_WEDDING_STUDIO_JOURNEY=off` 可关闭。
