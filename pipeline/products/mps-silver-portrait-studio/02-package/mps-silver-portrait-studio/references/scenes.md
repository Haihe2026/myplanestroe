## 消歧（特异主题/服饰 → 一般风格词 → 泛化氛围词）

- 先看特异主题或服饰：老兵/退役/军装 → veteran、唐装/中式 → tang、旗袍 → qipao、油画 → oil、园林/庭院 → garden、田园/乡村/乡间 → rural、海边/海滩 → beach、草坪/草地 → lawn、冬日/冬天/室内/家居 → winter、棚拍/影棚 → studio。
- 没有特异词时再看一般风格词（复古、古典、艺术、雅致、度假、户外）；只有「优雅」「银发」「阳光」「暖阳」这类泛化词时，先推荐一个稳妥方向再确认。泛化词不压过特异词：「优雅旗袍」→ qipao，「冬日暖阳」→ winter，「银发唐装」→ tang。不同层之间不看词序，只有同一层里才取原话最先出现的。`first-turn` 返回的 `suggested_scene` 已按这个顺序给出。
- 生日、父母节、金婚是送礼动机，不是主题，也不因此转全家福；只有三人及以上或寿宴多人场景才转。
- 「退休」不是「退役」；「当过兵」「部队里待过」含义不清时先问清楚长辈本人是否已退役，不替用户判断。
- 长辈海边单人纪念属于本技能，不当作旅行打卡；只有目的地打卡写真才转旅行打卡写真照相馆。唐装、旗袍是长辈单人纪念造型，不做婚礼造型；明确要婚礼写真才转婚纱写真照相馆。
- 多个都像时先推荐一个再问，首轮只给一个方向。

## 被摄人、代购与老兵条件

- 下单的人可以是被摄本人（`--orderer self`），也可以是家人代购（`--orderer family_proxy`）。代购时被摄本人必须知道并同意（`--informed yes`），由下单人转述；账户、次数和售后都属于下单的人，不转移、不合并。
- 被摄人必须是成年人（`--adult yes`）。没问到的填 `unknown`，脚本返回 `needsEligibility` 一次合并补问；明确未成年或明确不同意才停止。不看照片估计年龄，不收姓名、生日、关系证明或任何证件。
- 没有具体岁数或「必须全白发」的门槛：秃发不补发，灰黑发不强制变白，皱纹不加也不磨。
- 老兵纪念（veteran）只为被摄本人已退役（`--veteran retired_confirmed`）并同意该造型（`--veteran-consent yes`）的情况制作；条件属于被摄本人，不是下单人。没问到填 `unknown` → `needsVeteranInfo` 补问；`active` / `not_veteran` / 不同意 → `veteranNotApplicable`，可改选其他主题。不索要任何证明。服饰一律朴素无标识，不加军衔、勋章、番号、姓名牌、国徽军徽或武器，不复刻现役制服，不编造服役历史。
- 「爸妈各拍一张」拆成两份单人方案：各自一张单人照、各自的同意、各自确认和计费，不从一张合照里裁人。

## 通用规则

- 只接知情同意的成年被摄本人单人照（`--adult yes --single yes`，代购另需 `--informed yes`）。未经同意或名人照片、未成年人、儿童或孙辈入镜、两人合影、多人合成、换脸、返老还童或假老化、现役或非老兵的军装扮演、证件或服役证明一律不承接；三人及以上家庭合影或寿宴多人照转全家福写真照相馆，两人合影如实说本技能暂不支持。
- 脸部看不清或看不到图时，先请用户换一张更清楚的单人照（`--face-clear no`），不猜缺失的五官、年龄或民族。
- 三项同意缺一不提交：被摄本人对这张照片的许可、被摄本人同意把这张照片发送给图片服务及算力供应商处理、下单的人同意按张计费执行。付过款、亲属关系或资格自述都不能替代任何一项。
- 人物特征只用用户说出的可见特征；服装是选的风格，不推断性别、民族或身份。示例人物（虚构的 70 岁女性、短银发）的样貌不得套用到用户身上。
- 成品、示例和结果一览页都写明「AI 生成银发写真，非实拍」；不承诺与本人完全一致。
- 用户要修改时，每次只改一件事；一句话里提了多个修改，拆成多次生成依次完成。换照片、主题、服装、画幅，或下单人、同意情况变化，都要重新 `plan` 并重新确认。
- 证件照换底 → 证件照换底助手；本人孕期写真 → 孕妈写真照相馆；纯宠物写真 → 宠物主题照相馆。修图美颜、文字排版、视频、动图、线下预约、冲印邮寄、年龄或健康判断不承接。
- 只输出 PNG，每次 1 张；多张按单独任务逐张确认。
- 未命中路由表：按 prompts.md 的结构现场组合，不硬套，不扩大人数或画幅。

## 等待与超时（与脚本常量一致）

- 提交请求预算 90 秒；查询每次 15 秒，间隔 5 秒，最多 6 轮，轮询窗口 120 秒；计费前拒绝等待 0 秒；进程余量 30 秒。
- 宿主执行 run / resume 命令的外层超时不低于 240 秒。
- 对用户预估等待：1 到 4 分钟（设计预算，非实测）。
