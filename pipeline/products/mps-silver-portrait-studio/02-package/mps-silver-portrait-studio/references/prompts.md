# 描述结构（仅供执行，不对用户复述，不点名）

描述由 `scripts/studio.py` 的 `build_prompt()` 拼装，宿主不得自行改写或追加参数。固定五段顺序：

1. **真实性与人物身份（永远第一段）**：以被摄本人这张经同意的单人原图为唯一人物依据，画面里恰好 1 位成年人物；保留实际可见的脸部结构、五官比例、肤色、发型和体态，不设计新脸、不换脸、不增删人物；附上用户确认过的可见特征（如眼镜）。
2. **自然年龄外观**：按原照保留真实的发际线、发量，以及银发、灰发或黑发的实际分布，保留自然皱纹和岁月感；不磨皮扮嫩、不返老还童，也不强行染白、补发、加皱纹或做老化；不从外貌推断年龄或健康。
3. **主题与服装**：只按所选主题改变服装、背景和光影，见下表；服装用用户确认的选择，没说就用主题默认；服装只是风格，不推断性别、民族或身份。老兵纪念另加：外套上不出现军衔、勋章、番号、姓名牌、国徽军徽或武器，不表现现役身份、服役证明或军功。
4. **构图**：单人得体纪念肖像，脸部完整可见，姿态舒适自然。
5. **文字与安全**：图中不得出现任何文字、数字、可读招牌、标志、水印、边框或凭证；只有被摄本人一位成年人物，不出现儿童或其他人；不作医疗、法律或服役证明；不出现他人品牌和标志；手和手指形态自然。「AI 生成银发写真，非实拍」只写在交付文字和结果一览页里，不让画面里出现。

人物特征只用用户自己说出的可见特征；示例里的虚构人物特征（70 岁、女性、短银发、肤色）不得用于真实用户。对用户不展示拼装方式。空泛形容词（「好看一点」「年轻一点」）不进描述，换成下表里可核对的视觉描述；审美类细节自动用稳妥默认，不追问。

预告用语：「会尽力保持照片里可见的五官、发型和肤色，保留自然银发和皱纹，细节差异可能存在」，不承诺完全一致。
