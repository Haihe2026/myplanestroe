# 银发写真照相馆

发一张成年人的单人照——你本人，或者家人本人同意后由你代为下单——选一个主题，做成银发纪念写真。保留自然银发、皱纹和岁月感，不扮嫩；10 个主题，按张计费。成品是 AI 生成银发写真，非实拍。

## 适合

- 想要影棚感：优雅银发棚拍、唐装中式、旗袍雅致、复古油画
- 想要自然光：户外草坪阳光、海边度假暖阳、园林雅致、田园乡村
- 想要温暖居家氛围：冬日暖阳室内
- 纪念老兵：军装老兵纪念（只为本人已经退役并同意的长辈制作，朴素无标识，不带军衔勋章）
- 送给爸妈的生日、节日或金婚礼物：一人一张，各自同意、分别制作

## 不做

- 未经本人同意的照片、名人或他人的照片、未成年人
- 两人或多人合影，加入孩子、孙辈或其他人，把几张照片里的人拼到一起，换脸
- 返老还童或假老化、现役或其他身份的军装扮演、军衔勋章；证件照、医学或服役证明、年龄或健康判断
- 三人及以上的家庭合影或寿宴多人照 → 全家福写真照相馆；婚礼写真 → 婚纱写真照相馆；目的地旅行打卡 → 旅行打卡写真照相馆；孕期写真 → 孕妈写真照相馆；证件照换底 → 证件照换底助手；宠物写真 → 宠物主题照相馆
- 普通修图美颜、文字排版、视频、动图、线下预约、冲印邮寄

## 示例效果（10 个）

优雅银发棚拍、唐装中式、户外草坪阳光、复古油画、海边度假暖阳、旗袍雅致、园林雅致、军装老兵纪念、田园乡村、冬日暖阳室内。示例人物均为虚构的同一位成年人，只展示效果方向，不是你的真实结果；老兵纪念示例只是虚构设定；每张都是 AI 生成银发写真，非实拍。

## 收费

按张计费，档位和金额在充值页上；同一账户的通用次数在已接入的技能间共享。没有免费试用。替家人下单时从你自己的账户扣次数。可以随时查剩余次数和消费记录。

## 反馈

有问题或建议直接说，确认原话后提交反馈，会给你一个反馈编号；之后说「查工单」就能看到处理进度和回复。提交反馈不扣次数。

## 说明

- 结果由 AI 生成，是银发纪念写真，不是实拍；会尽力保持五官与发型，但可能与本人有差异。
- 服装只是选的风格，不代表性别、民族或其他身份。
- 原照片不改动，结果另存为新的 PNG 文件。
- 首次对话会上报一次匿名安装标识和技能版本，仅用于统计使用情况和安装绑定，不含聊天内容、照片、年龄或家人信息；设置环境变量 `MPS_SILVER_PORTRAIT_JOURNEY=off` 可关闭。
