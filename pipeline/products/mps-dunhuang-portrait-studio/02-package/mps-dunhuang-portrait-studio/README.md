# 敦煌写真照相馆

上传一张你本人的清晰单人照，选择敦煌飞天、壁画或沙漠方向，做一张艺术写真。服装、飘带、璎珞、发髻和妆容配套，尽力保持本人五官和自然外貌。

## 示例效果（10 个）

飞天反弹琵琶、敦煌壁画仙女、莫高窟飞天、鸣沙山沙漠飞天、月牙泉夜景飞天、敦煌乐舞飞天、飞天水袖舞、敦煌古装仕女、沙漠驼队飞天、星空沙漠飞天。
示例人物均为虚构的同一位成年人，只展示效果方向，不是你的真实结果；AI 生成敦煌写真，非实拍。飞天可以落地，仕女可静坐；反弹琵琶姿势容易失真，月牙泉为远处小型水面，水袖为现代舞台演绎。

## 怎么用

发本人清晰单人照，说明喜欢的方向。先看效果示例，确认本次照片使用、发送处理和按张制作后，再开始。每次先做一张；想调整就说，每次先改一件事，需要重新制作时会先确认可能再次计费。

## 范围

仅成年人本人单人照，不做儿童、双人/多人、他人代拍或换脸；不承接纯汉服形制、婚纱/婚服、旗袍、和服、军装、其他城市地点写真、证件或证明用途、普通调曝光/裁剪/去噪、视频或动图。鸣沙山、月牙泉、莫高窟属于敦煌艺术方向，照片不是到访证明。结果不是实拍或文物复原，人物、衣饰和背景细节可能有差异；不能保证像素级相似或历史准确。
