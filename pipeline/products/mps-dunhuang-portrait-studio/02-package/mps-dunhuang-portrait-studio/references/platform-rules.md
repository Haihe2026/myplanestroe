# 照片与使用须知（可向用户转述）

- 发一张本人清晰PNG或JPG单人照：不超过5MiB，最短边至少128像素、最长边不超过8000像素、总像素不超过2000万，单帧；不接动图或网页链接。
- 只做成年人本人。没有确认时先问，不从照片猜年龄/民族/健康，不索证件。明确未成年、不是本人或不同意时停止，不让人换张图绕过事实。
- 服装、飘带、饰物、发髻和妆容按同一敦煌方向配套，不混穿纯汉服、和服、婚纱/婚服、旗袍或军装；不加儿童/他人，不做换脸或证件。
- 反弹琵琶手部/姿态可能失真；飞天可以落地，仕女可静坐，水袖为现代舞台演绎。作品不是文物复原、景区实拍、到访证明或真实天象记录。
- 默认竖版，另可方图或横版。画幅与实际结果可能有偏差，按实际文件说明；不保证打印质量或像素级相似。
- AI 生成敦煌写真，非实拍；会尽力保持五官与自然外貌，细节可能有差异。公开发布时按所在平台要求标注AI生成。
- 原照片不改动，结果另存PNG，不覆盖原文件。处理前分别确认照片使用、发送给图片服务及算力供应商及本次按张计费；充值或授权登录不能代替同意。
- 处理留存以实际页面披露为准；不承诺处理后立即删除、交图后结果立即删除或统一保留一小时。
