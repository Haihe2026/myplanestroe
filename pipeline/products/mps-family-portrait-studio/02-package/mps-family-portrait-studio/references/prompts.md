# 描述结构（仅供执行，不对用户复述，不点名）

描述由 `scripts/studio.py` 的 `build_prompt()` 拼装，宿主不得自行改写或追加参数。结构为「动作动词 + 具体视觉参照 + 锁定句」，固定顺序：

1. **真实性与人物身份（永远第一段）**：以这张合照为唯一人物依据，恰好 3 或 4 位人物，人数和从左到右的相对位置不变；**逐人指代、逐人锁定**（第 1 位左一……），每位分别保留五官比例、发型、肤色、年龄外观、体型和用户确认过的可见特征（如眼镜）；不混脸、不互换、不融合、不新增或删除人物。不用「所有人」一句话代替。
2. **动作 + 视觉参照**：只按所选主题改变服装、背景和光影，见下表；所有人的脸完整可见，光影和构图自然统一。
3. **文字基线**：图中不得出现任何文字、数字、水印、标志或边框。
4. **安全基线**：不添加额外人物，不出现他人品牌和标志；手和手指形态自然，不出现多余肢体。

人物特征只用用户自己说出的可见特征，不推断亲属关系、真实年龄、民族或健康；对用户不展示编号和拼装方式。空泛形容词（「好看一点」「高级一点」）不进描述，换成下表里可核对的视觉描述；审美类细节自动用稳妥默认，不追问。
