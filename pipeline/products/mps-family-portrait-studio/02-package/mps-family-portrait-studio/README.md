# 全家福写真照相馆

发一张 3 到 4 人的家庭合照，选一个主题，做成主题全家福。人数和站位保持不变，尽量保留每个人的样子；10 个主题，按张计费。

## 适合

- 过年、圣诞想要一张有节日氛围的全家福：新年红团圆照、圣诞节日
- 给长辈祝寿留念：寿宴金寿
- 想给家庭合照换个风格：中式工笔画、复古油画、简约棚拍、韩式清新
- 想要户外感的合照：户外草坪、海边度假、田园乡村

## 不做

- 1 到 2 人的照片、5 人以上的合照
- 把几张不同的照片拼成一张合照，换脸，或加入不在合照里的人
- 照片里有人没同意，或未成年人没有监护人同意
- 一两个人的婚纱照或写真 → 婚纱写真照相馆；证件照换底 → 证件照换底助手；宠物写真 → 宠物主题照相馆
- 普通修图美颜、文字排版、视频、动图、线下拍摄预约、冲印邮寄

## 示例效果（10 个）

新年红团圆照、中式工笔画全家福、户外草坪全家福、简约棚拍全家福、复古油画全家福、海边度假全家福、圣诞节日全家福、寿宴金寿全家福、韩式清新全家福、田园乡村全家福。示例人物均为虚构的成年人，只展示效果方向，不是你的真实结果。

## 收费

按张计费，档位和金额在充值页上；同一账户的通用次数在已接入的技能间共享。没有免费试用。可以随时查剩余次数和消费记录。

## 反馈

有问题或建议直接说，确认原话后提交反馈，会给你一个反馈编号；之后说「查工单」就能看到处理进度和回复。提交反馈不扣次数。

## 说明

- 结果由 AI 生成，会尽力保持每个人的五官与身份特征，但可能与本人有差异。
- 原照片不改动，结果另存为新的 PNG 文件。
- 首次对话会上报一次匿名安装标识和技能版本，仅用于统计使用情况和安装绑定，不含聊天内容和照片；设置环境变量 `MPS_FAMILY_PORTRAIT_JOURNEY=off` 可关闭。
