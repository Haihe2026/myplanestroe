隐私政策

版本：2026-10-23 · 发布日期：2026年10月23日

运营主体及个人信息处理者：珠海市香洲区拱北理想家电子商贸行。本政策说明 MyPlaneStore 网站与关联创作账户如何处理个人信息，并单独说明儿童照片服务的开放条件。各技能、宿主平台和图片处理服务的处理范围不因使用同一个账户而自动相同。

请先了解：账号手机号用途同意与照片处理同意分开。阅读本政策、注册、绑定账户或付款，不视为同意提交儿童照片，也不视为同意任何未告知的第三方处理或跨境提供。

一、信息类别、目的与必要性

  • 账户关联：您自填的手机号仅用于关联与恢复创作账户。当前不发送短信验证，不据此认定实名或号码持有权。服务器保存手机号的密钥散列索引及尾四位、随机 KEY 的加盐强哈希；不将完整手机号或 KEY 明文写入账户表。为向当前 Skill 私密交付 KEY，可将 KEY 加密暂存最多24小时，收到该客户端保存确认后清除可领取密文；超期停止领取并定期清理，不因此重置原 KEY。尾号不能单独用于登录或补发 KEY。
  • 交易与余额：处理匿名账户编号、套餐、订单、付款申报、核款结果及次数流水，用于提供服务、履行交易和售后。网站不因用户点击“已付款”就认定到账。
  • 安全与会话：必要的会话 Cookie、短期授权票据、设备关联标识、IP地址及请求时间、结果等技术记录，用于身份认证、防止滥用、故障排查和安全审计。不同意可退出登录或清除 Cookie，部分账户功能会无法使用。
  • 一般图片服务：仅在您主动请求制作并确认相关说明后，按该任务需要处理提示词、参考图片及生成结果。不同产品的原有留存规则不因本页的儿童照片专门规则而自动改变；任务提交前应单独告知适用处理方和期限。

二、保存、安全与账户权利

账户关联信息在提供账户服务所需期间保存。您可申请查阅、复制、更正、解除关联或注销。注销时删除不再必要的账户信息；法律要求保留的交易、安全或争议处理记录按适用法定期限限制用途，不用于重新营销。具体请求可向客服提出，我们将在核实必要的原账户凭证后答复；不会要求您在公开聊天发送完整 KEY、儿童照片或身份证明原件。

我们采取加密传输、权限限制和凭据哈希等措施。请私密保存 KEY，不将其交给他人。图片下载到您设备、您使用的宿主平台或您主动保存的位置后，相应副本由该设备或平台管理；网站不能替您删除这些副本。不能把“网站删除”理解为互联网上所有副本均已删除。

三、委托处理及服务地区

网站面向中国大陆用户。“面向中国大陆用户”不等于信息全部在中国大陆境内处理：当前网站使用中国大陆境外服务器。我们不以本政策承诺现有全部数据仅在境内存储。儿童照片如要求仅在中国大陆境内处理，必须先落实相应处理链路并明确告知处理地点，未落实前不开放该照片功能。

涉及委托处理，应限定目的、期限、方式、信息种类和保护措施，并约定删除、返还和监督义务；需向其他独立处理者提供或向境外提供个人信息时，应依法履行相应告知、单独同意及其他适用程序，不以本政策或一次账户绑定替代。未经授权，不将儿童照片用于公开展示、广告、身份识别或模型训练。

四、儿童个人信息保护专门规则

不满十四周岁未成年人的个人信息属于敏感个人信息。儿童照片制作仅面向其父母或其他监护人操作。处理前须说明具体任务目的、必要信息、对权益的影响、实际受托方、处理与存储地点、期限和删除方式，并取得监护人针对该任务的独立、明确同意；不预勾选，不与手机号用途或付款同意捆绑。拒绝或撤回照片同意不影响与照片处理无关的账户查询服务。

当前留存说明：现有图片生成、编辑与下载链路可能存储任务图片，不能视为零留存。运营主体已确定以下删除目标，但在相应能力落实前，不将目标表述为已兑现的服务能力。正常参考图处理按现有服务能力与任务授权进行，本政策不额外设置产品审批流程。

宝宝照片服务的目标规则：仅处理完成当前制作所必要的照片和要求；向用户完成结果交付后，立即停止为该任务留存原图、生成结果及中间副本，不另建相册、展示库或照片备份。这里的交付须由客户端确认成功接收，不能仅以生成了链接代替。若处理系统、缓存、备份或受托方无法做到，应先调整系统或重新明确告知并取得必要同意，不能在保留副本的同时宣传“即刻删除、无副本”。本目标取代此前宝宝照片“24小时留存”的拟定方案；不适用于其他产品或既有历史图片。

开放前须核实原图、临时副本、成品、缓存、备份和受托处理副本的实际删除范围；未明确的供应商留存不能视为零留存。依法必须保留的非图像授权、安全或交易记录应与照片内容分离，并按必要期限限制使用。

撤回与删除：监护人可经下方客服要求停止相关任务、撤回同意、更正或删除信息，并提供原任务编号或原账户凭证以便核对。经确认后停止后续处理，删除不再必要的照片及可控副本，并联系相关受托方处理其副本、反馈实际结果及无法立即删除的合法理由。不会以仅隐藏链接、清除页面或修改状态代替实际删除。照片删除后可能无法继续制作、补下载或恢复，请及时保存您需要的结果。

儿童信息保护事务由运营主体受理并落实专人负责。若发生信息安全事件，将采取止损、补救和依法通知、报告等措施。处理目的、范围或主体等发生实质变化时，重新告知并取得相应同意。

已启用的新任务删除策略：对主动选择“交付后删除”策略的新通用图片任务，网关在成品写入任务数据库前加密。客户端确认收到并校验原图后，或本人主动要求删除时，清除网关在线成品并销毁其独立解密密钥；未领取成品最多保留1小时，到期停止下载并自动清理。服务重启不重建任务；主机重启或密钥丢失时，成品可能无法恢复，仍保留原任务及计费记录，避免重复生成和扣量。原参考图在该同步网关中用于内存校验与本次传输，相关上传与下载代理已关闭图片临时文件缓冲。以上不代表供应商、未知主机快照或用户本地副本均已删除，也不改变其他产品及未启用新策略的历史任务。

五、联系方式与投诉

个人信息保护、儿童信息保护、删除、撤回、账户注销及投诉，请联系运营主体客服微信：GMC2B2022，并注明“隐私请求”。客服可转交个人信息保护负责人处理。我们仅核验完成请求所必要的信息；如认为权益受到侵害，您也可向有管辖权的网信等主管部门反映。
