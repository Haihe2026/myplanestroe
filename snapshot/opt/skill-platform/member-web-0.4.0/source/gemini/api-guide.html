Gemini生图助手生图 API

生图 API 接口

接入地址 https://myplanestore.com/v1，模型标识 gpt-image-2。只支持单张文生图，不是通用 token 或全功能 OpenAI 兼容服务。会员经客服核款到账后可领取。

认证与额度

在会员中心领取专属 Key，发送 Authorization: Bearer <YOUR_KEY>。不要使用你的算力平台 Key。API 与 WorkBuddy 共用额度，不能重复领取试用。撤销后新请求失效，已提交任务仍可能完成。

生成图片

POST /v1/images/generations，Content-Type 为 application/json。必须发送长度16–100的 Idempotency-Key：同一需求重试必须沿用它，换需求使用新标识。

{
  "model": "gpt-image-2",
  "prompt": "明亮办公室里的协作场景，用于内部培训配图",
  "n": 1,
  "size": "1024x1024",
  "response_format": "b64_json"
}

支持尺寸以账户预设为准，默认1024x1024。可附加role/platform/slot，使用Skill岗位库的实际编码。不可请求编辑图片、批量生成、文本、视频或传任意上游地址。参数不受支持会拒绝，不会悄悄忽略。

响应与恢复

200返回 data[0].b64_json、job_id、balance_points。202表示结果待核查，不是已完成，也不是未扣额度；不要自动换任务重试。用同一 Key 查询 GET /jobs/{job_id}；成功后访问 GET /jobs/{job_id}/image 返回PNG。余额：GET /balance，展示字段balance_points。

限制与安全

默认每账户每天最多100次API请求预占/成功生成，并发待处理最多2个；余额耗尽返回402，限流429。免费账户不能领取 Key；当前仅支持终身付费档资格，月度权限待周期结算实现后开放。服务器只保存Key哈希和前缀，明文只展示一次；丢失请撤销并重领。每账户最多2个有效Key。请在自己的后端保存Key，不要嵌入公开网页。
