# Skill三渠道交付摘要
每款Skill分别封装WorkBuddy技能、WorkBuddy专家、SkillHub三个渠道，不互相混用分类和包结构。保留核心源码与旧版交付，适配另出新包；头像与对应ZIP同目录。负责人自行上传，除非另有明确授权。
每渠道记录版本、ID或slug、链接、本地验证、宿主试用及审核状态。平台分类必须核对当前真实选项。没有实测的宿主包不得声称安装测试或审核通过。
网站接入只用站点客户接口和本地客户端凭证；不把供应商Key、管理员权限或生产Cookie放进Skill。示例只用合成或脱敏资料，保留第三方授权声明，不擅自赋予开源许可。
完整内部SOP不公开。本文件是供外部开发者阅读的交付摘要。
