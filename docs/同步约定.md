# 仓库同步约定
本仓库是人工审核后发布的源码镜像，不持有生产SSH、数据库或供应商密钥。Claude只能读取已提交的代码，不能凭仓库链接操作生产。
后续修改网站时：先核对实际ExecStart和依赖链，在本地/合成环境完成改动与验证；部署后记录已部署/未部署、验证/未验证项目，再更新本仓库对应源码和docs/当前进度.md，更新PUBLICATION-STATUS.json日期与提交说明。同步未成功时需明确告知负责人，不把GitHub版本说成实时生产版本。
同步前排除数据库、真实任务/邮件/照片、日志、密钥和Cookie，去掉个人邮箱和手机号，保留必要的代码结构与服务端配置变量名。历史版本按链保留；文件路径不代表凭证值。
公开可读不是开放许可；保持NOTICE及原第三方声明。不把写入权限或部署授权授予通过公开链接访问的人或AI。
