# 复制给各 Skill 项目的升级指令

请为当前 Skill 新增 MyPlaneStore 首次回话上报，保留现有功能、登录和计费。请先读本项目规则，按实际发布渠道分别封装，保留旧包，由负责人上传，不替负责人发布。

## 触发与数据
用户实际发送第一条消息并唤起本 Skill 时触发，包括问候、能力询问；不要等注册、充值或业务请求。下载、安装、读取文件、定时任务、自检不算。仅尽力上报；宿主不执行工具、拒绝联网或丢失本地状态均可能漏报，不能宣称覆盖所有对话。
只记录事件时间、Skill 标识/名称/版本和渠道，不传聊天正文、提示词、照片、文件、电话、邮箱、客户资料、系统指纹或任何账户凭证。按宿主权限与隐私告知要求执行，不绕过授权；原有“无联网/无统计”说明须据实更新。

## 一次性元数据上报
为本次安装生成独立随机 UUID installation_id，为事件生成独立随机 UUID event_id（标准小写带连字符）。不得复用 install_secret。使用当前项目自己的私有状态目录持久化，按 Skill×渠道维护；不要猜其他项目凭证路径，也不要按每个新对话重建。
POST https://aistore.zhaopintong.com/platform-api/telemetry/v1/first-dialogue
Content-Type: application/json；此请求不带账户凭证，JSON 不超过4096字节：
```json
{"event_id":"<随机UUID>","installation_id":"<独立随机UUID>","skill_id":"<真实slug或固定ID>","skill_name":"<公开名称>","skill_version":"<实际版本>","channel":"skillhub","client_occurred_at":"<带时区ISO时间>","is_test":false}
```
channel 只能为 skillhub、workbuddy_skill、workbuddy_expert，必须匹配当前包。skill_id 为2–100位小写字母、数字、下划线或横线，首字符字母或数字；skill_name 1–100字；skill_version 最长40字；可省略客户端时间和版本，不伪造时间。
200 返回 event_id、received_at（Unix秒，服务端接收时间）、receipt、duplicate。保存服务端返回的 event_id 和 receipt，并标记已上报；重复上报可能返回原事件ID，须采用返回值。receipt 不是账户登录凭证，不展示给用户。
网络超时建议1–2秒，失败不得阻塞正常回答或重复扣费。失败留本地待重试，后续交互退避重试，始终复用原安装ID和事件ID，不循环轰炸。400修正字段，429退避，503稍后重试。状态丢失或重新安装可能重新计事件，不能当作独立用户数。

## 关联现有账户（有凭证时再做）
未登录照样先上报，不要求注册。若 Skill 已持有自己的合法账户凭证，或以后完成现有账户关联，再请求：
POST https://aistore.zhaopintong.com/platform-api/telemetry/v1/first-dialogue/link
Authorization: Bearer <现有账户凭证>；Content-Type: application/json
```json
{"event_id":"<服务端返回ID>","receipt":"<服务端返回回执>","product":"gemini"}
```
product 取当前真实通道 gemini / temu / pet / trade-leads；trade-leads 还须带现有 X-Device-Id，遵循原设备鉴权。无这些通道账户的免费 Skill 不调用关联接口，保留未关联记录即可。不提交 user_id，不另建账户，不发放额度，不改登录或支付逻辑。200表示成功，401应走原账户恢复流程，409不得覆盖其他账户关联。凭证只放请求头，不进正文、日志、展示内容或交付包。

## 验证与交付
本地使用合成数据和 Mock HTTP 验证：第一条消息上报一次、重复交互不上报、失败重试不重复、未注册可上报、关联后回执只绑定真实鉴权账户、不同渠道独立、不泄露正文/凭证。测试事件设 is_test:true；不调用真实生图或数据供应商。列明未实际做过的宿主测试，不能宣称已上线。
后台入口仍是“用户与额度”：已关联与未关联首次互动在同一列表按服务端接收时间展示，关联后归入对应账户，旅程显示各 Skill。未上报不等于未说话，历史下载不能补造首次回话时间。
